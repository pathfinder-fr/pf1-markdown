{s:BDTitre|Elixir de vision dans les ténèbres|{s:MR}}
**Aura** [Transmutation](./Transmutation.md) modérée ; **NLS** 6 ; **Emplacement** [aucun](./Objets merveilleux sans emplacement.md) ; **Prix** 1 200 po ; **Poids** —
(((Description)))
Ce liquide sombre et sirupeux double la portée de la [vision dans le noir](./vision dans le noir.md) du buveur et lui permet de voir malgré des *[ténèbres profondes](./Ténèbres profondes.md)* quand il utilise vision dans le noir. L’effet dure 1 heure.
(((Création)))
**Conditions** [Création d’objets merveilleux](./Création dobjets merveilleux.md), *[sort vision dans le noir](./sort Vision dans le noir.md)*, *[ténèbres profondes](./Ténèbres profondes.md)* ; **Coût** 600 po
