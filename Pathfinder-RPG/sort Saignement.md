{s:Desambi|Saignement est également le nom d'une [capacité spéciale](./Saignement.md). Voir aussi [ici](./Saignement (capacité).md).}
**École** [Nécromancie](./Nécromancie.md) ; **Niveau** [Cham](./Chaman.md) 0, [Hyp](./Hypnotiseur.md) 0, [Inq](./Inquisiteur.md) 0, [Ens](./Ensorceleur.md)/[Mag](./Magicien.md) 0, [Méd](./Médium.md) 0, [Occ](./Occultiste.md) 0, [Prê](./Prêtre.md) 0, [Psy](./Psychiste.md) 0, [Sor](./Sorcière.md) 0, [Spi](./Spirite.md) 0  

**Temps d'incantation** 1 [action simple](./Action simple.md)  

**Composantes** [V, G](./composantes.md)  

**Portée** courte (7,50 m + 1,50 m/2 [niveaux](./niveau.md)) (5 {s:c} + 1 {s:c}/2 [niveaux](./niveau.md))  

**Cible** une créature vivante  

**Durée** [instantanée](./instantanée.md)  

**Jet de sauvegarde** [Volonté](./Volonté.md), [annule](./Présentation des sorts.md#JETSDESAUVEGARDE) ; **Résistance à la magie** oui

À cause du personnage, une créature qui se trouvait sous 0 points de vie mais s’était [stabilisée](./Stable.md) recommence à agoniser. Le lanceur de sorts vise une créature qui possède -1 point de vie ou moins. Celle-ci perd alors un point de vie par [round](./round.md). On peut la [stabiliser](./Stable.md) ensuite normalement mais le sort fait perdre 1 point de vie à toute créature [mourante](./Mourant.md).
