{s:APG}**École** [Évocation](./Évocation.md) <nowiki>[</nowiki>[lumière](./Registre.md)<nowiki>]</nowiki> ; **Niveau** [Bard](./Barde.md) 1, [Dru](./Druide.md) 1, [Ens](./Ensorceleur.md)/[Mag](./Magicien.md) 1, [Magus](./Magus.md) 1, [Psy](./Psychiste.md) 1, [San](./Sanguin.md) 1
**Temps d'incantation** 1 [action simple](./Action simple.md)
**Composantes** [V](./composantes.md)
**Portée** courte (7,5 m + 1,5 m/2 [niveaux](./niveau.md)) (5 {s:c} + 1 {s:c}/2 [niveaux](./niveau.md))
**Cible** rayonnement de lumière de 3 m (2 {s:c}) de rayon
**Durée** [instantanée](./instantanée.md)
**Jet de sauvegarde** [Vigueur](./Vigueur.md), [annule](./Présentation des sorts.md#JETSDESAUVEGARDE) ; **Résistance à la magie** oui
---
Ce sort fonctionne comme *[illumination](./Illumination.md)* mais il affecte toutes les créatures qui se trouvent dans un rayon de 3 mètres (2 {s:c}) à partir du point d'impact.

## Illumination
**École** [Évocation](./Évocation.md) <nowiki>[</nowiki>[lumière](./Présentation des sorts.md#REGISTRE)<nowiki>]</nowiki> ; **Niveau** [Bard](./Barde.md) 0, [Dru](./Druide.md) 0, [Hyp](./Hypnotiseur.md) 0, [Ens](./Ensorceleur.md)/[Mag](./Magicien.md) 0, [Magus](./Magus.md) 0, [Méd](./Médium.md) 0, [Occ](./Occultiste.md) 0, [Psy](./Psychiste.md) 0

**Composantes** [V](./composantes.md)

**Effet** [rayonnement](./rayonnement.md) de lumière
**Durée** [instantanée](./instantanée.md)

Ce sort élémentaire crée une petite explosion de lumière. Si celle-ci se produit devant une seule créature, cette dernière doit réussir un jet de [Vigueur](./Vigueur.md) pour éviter de se retrouver [éblouie](./Ébloui.md) pendant une minute. Les créatures  [aveugles](./Aveuglé.md), ainsi que celles qui sont déjà [éblouies](./Ébloui.md), ne sont pas affectées par *illumination*.
