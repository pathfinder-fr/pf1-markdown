Dans certaines circonstances, indiquées dans le profil du monstre (lorsqu’il fait une [attaque à outrance](./attaque à outrance.md) ou une attaque d’[éventration](./Éventration (capacité).md), par exemple), celui-ci peut aussitôt tenter une attaque de plus contre un adversaire. Cette attaque utilise le [bonus de base à l’attaque](./BBA.md) maximal de la créature, auquel se rajoutent les modificateurs appropriés à la situation. Cette attaque supplémentaire ne se cumule pas avec les autres méthodes permettant de gagner des attaques supplémentaires comme le sort *[rapidité](./Rapidité.md)* ou les armes *[rapides](./rapide (propriété).md)*. Ce pouvoir n’offrant pas d’action supplémentaire, le personnage ne peut pas s’en servir pour lancer un deuxième sort ou accomplir une action supplémentaire dans le [round](./round.md).

*Format :* sauvagerie féroce (attaque à outrance) ; *Emplacement :* Attaques spéciales.
