**Bonus d'armure** +1 ; **Bonus de Dex maximal** +8 ; **Malus d'armure** 0
**Risque d'échec des sorts profanes** 10% ; **Vitesse** 9 m/6 m (6 c/4 c)

Cette version améliorée de l’[armure matelassée](./armure matelassée (armure).md) est constituée de couches internes spécifiquement conçues pour piéger les [flèches](./Flèches (arme).md), les [carreaux](./Carreaux darbalète (arme).md), les [fléchettes](./fléchette (arme).md), les [shurikens](./Shurikens (arme).md), les [dagues](./dague (arme).md) de jet et autres petites armes à distance perforantes. Lorsque l’une de ces armes frappe le personnage, elle se fiche dans les épaisseurs et n’arrive pas à le blesser. Le vêtement rembourré donne au personnage une [RD](./RD.md) 3/— contre les attaques de ce genre. Les couches spéciales de l’armure n’ont aucun effet sur les autres types d’armes.
