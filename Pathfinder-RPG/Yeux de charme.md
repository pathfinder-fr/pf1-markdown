<div class="BD">
{s:BDTitre|Yeux de charme|}
**Aura** [Enchantement](./Enchantement.md) modérée ; **NLS** 7 ; **Emplacement** [yeux](./Objets merveilleux portés sur les yeux.md) ; **Prix** 56 000 po pour une paire ; **Poids** —
(((Description)))
Ces lentilles de cristal se fixent sur les yeux de leur porteur, qui peut ensuite lancer *[charme-personne](./Charme-personne.md)* rien qu’en croisant le regard de ses cibles (une par round). Si celles-ci ratent un jet de [Volonté](./Volonté.md) ([DD](./DD.md) 16), elles se retrouvent charmées. Il faut porter les deux lentilles pour que l’objet magique fasse effet.
(((Création)))
**Conditions** Augmentation d’intensité, [Création d'objets merveilleux](./Création dobjets merveilleux.md), *[charme-personne](./Charme-personne.md)* ; **Coût** 28 000 po pour une paire
