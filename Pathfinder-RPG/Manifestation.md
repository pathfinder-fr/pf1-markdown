{s:UM}
**Niveau** 4

Ce mot change le type de [jet de sauvegarde](./jet de sauvegarde.md) de certains mots effet utilisés dans le sort. Si l’effet requiert un jet de [Volonté](./Volonté.md), il est remplacé par un jet de [Vigueur](./Vigueur.md). Ce changement n’a pas d’influence sur le fait que le [jet de sauvegarde](./jet de sauvegarde.md) annule l’effet, le réduit ou provoque d’autres effets ; il modifie simplement le type de [jet de sauvegarde](./jet de sauvegarde.md) requis.
