<div class="BD">
{s:BDTitre|Anneau de triple souhait|{s:AE}}
**Aura** [Évocation](./Évocation.md) ou [Universelle](./Universelle.md) puissante (si *[miracle](./Miracle.md)* est utilisé) ; **NLS** 20 ; **Emplacement** [anneau](./Anneaux magiques.md) ; **Prix** 120 000 po ; **Poids** —
(((Description)))
Cet anneau est serti de trois rubis. Chacun d’entre eux stocke un sort de *[souhait](./Souhait.md)* auquel le porteur peut faire appel quand il le souhaite. Dès qu’un *[souhait](./Souhait.md)* est utilisé, le rubis correspondant disparaît. Si l’anneau est déterminé aléatoirement, lancez 1d3 afin de déterminer le nombre de rubis restants. Une fois tous les *[souhaits](./Souhait.md)* utilisés, l’anneau devient non magique.
(((Création)))
**Conditions** [Création d'anneaux magiques](./Création danneaux magiques.md), soit *[souhait](./Souhait.md)*, soit *[miracle](./Miracle.md)* ; **Coût** 97 500 po
