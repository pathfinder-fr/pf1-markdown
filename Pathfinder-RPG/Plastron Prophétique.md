<div class="BD">
{s:BDTitre|Plastron prophétique|{s:AE}}
**Aura** [Divination](./école divination.md) faible ; **NLS** 3 ; **Emplacement** [torse](./Objets merveilleux portés sur le torse.md) ; **Prix** 6.000 po ; **Poids** 0,5 kg
(((Description)))
Les pierres sacrées, les étoiles et les inscriptions pleines de sagesse ancestrale gravées sur ce plastron améliorent les chances de succès des sorts d’*[augure](./Augure.md)*, de *[divination](./Divination.md)* et de *[contact avec les plans](./Contact avec les plans.md)*. Le porteur ajoute 1d6 au d100 lancé lorsqu’il lance l’un de ces sorts. Quand il lance les sorts *[communion](./Communion.md)* ou *[communion avec la nature](./Communion avec la nature.md)*, le porteur peut poser une question de plus ou obtenir une information supplémentaire.
(((Création)))
**Conditions** [Création d’objets merveilleux](./Création dobjets merveilleux.md), *[divination](./Divination.md)*, *[assistance divine](./Assistance divine.md)*  ; **Coût** 3.000 po
