Les bottes à lame possèdent un couteau à ressort qui sort lorsqu'il est déclenché avec la bonne combinaison de pressions avec les orteils. Le personnage peut utiliser une botte à lame comme [arme secondaire](./Actions spéciales.md#COMBAT2ARMES). Faire sortir le couteau est une [action rapide](./Action rapide.md) ; le réarmer est une [action complexe](./Action complexe.md). Lorsque le couteau est sorti, le personnage traite le terrain normal comme du [terrain difficile](./terrain difficile.md) et le terrain difficile comme infranchissable.
