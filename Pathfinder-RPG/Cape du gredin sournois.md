<div class="BD">
{s:BDTitre|Cape du gredin sournois|{s:MCA}}
**Aura** [Abjuration](./Abjuration.md) modérée ; **NLS** 5 ; **Emplacement** [épaules](./Objets merveilleux portés sur les épaules.md) ; **Prix** 6 400 po ; **Poids** 1 kg
(((Description)))
Cette cape bordeaux foncé change de couleur et de motifs pour mieux se fondre dans son environnement, accordant au personnage un bonus de compétence de +5 aux tests de [Discrétion](./Discrétion.md). La cape est équipée d’un fourreau dissimulé dans lequel il est possible de cacher une lame légère (comme défini dans le [groupe d’armes](./groupe darmes.md#Lameslégères) du guerrier). Le personnage peut dégainer cette lame comme s’il s’agissait d’un fourreau normal mais quiconque fouille le personnage pour trouver l’objet doit réussir un test de [Perception](./Perception.md) [DD](./DD.md) 20, comme s’il cherchait un passage secret.
Si un [bretteur](./Bretteur.md) porte la cape, il peut dépenser 1 point de [panache](./panache.md) pour bénéficier de *[disparition](./Disparition.md)*, comme le sort.
(((Création)))
**Conditions** [Création d’objets merveilleux](./Création dobjets merveilleux.md), *[disparition](./Disparition.md)*, *[réduction d’objet](./Réduction dobjet.md)* ; **Coût** 3 200 po
