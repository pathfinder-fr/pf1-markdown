**Aura** Variable modérée ; **NLS** 8 ; **Emplacement** aucun ([bâton](./Bâtons magiques.md)) ; **Prix** 23 000 po ; **Poids** 2,5 kg
(((Description)))
Ce gros bâton fonctionne comme un *bâton +1/+1*. Il permet d'utiliser les sorts suivants :
• *[silence forcé](./Silence forcé.md)* (1 charge)
• *[interrogatoire](./Interrogatoire.md)* (1 charge)
• *[ennui oppressant](./Ennui oppressant.md)* (2 charges)
(((Création)))
**Conditions** [Création de bâtons magiques](./Création de bâtons magiques.md), *[silence forcé](./Silence forcé.md)*, *[interrogatoire](./Interrogatoire.md)*, *[ennui oppressant](./Ennui oppressant.md)* ; **Coût** 11 800 po
