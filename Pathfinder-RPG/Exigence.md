Ce sort fonctionne comme *[communication à distance](./Communication à distance.md)*, à ceci près que le message peut également contenir une *[suggestion](./Suggestion.md)* (voir le sort de même nom) à laquelle le sujet obéit du mieux qu’il peut. Un jet de [Volonté](./Volonté.md) réussi annule la *[suggestion](./Suggestion.md)*, mais pas le contact proprement dit. Si le sujet reçoit le message, il le comprend, même si son [Intelligence](./Intelligence.md) n’est que de 1. Si le message envoyé correspond à une action impossible ou s’il n’a aucun sens étant donné les circonstances dans lesquelles le sujet se trouve lorsqu’il le reçoit, le sujet le comprend mais la *[suggestion](./Suggestion.md)* n’a aucun effet.

Le message transmis ne peut dépasser vingt-cinq mots, *[suggestion](./Suggestion.md)* y compris. La créature peut également transmettre une courte réponse immédiatement après avoir reçu le message.

## Communication à distance
**École** [Évocation](./Évocation.md) ; **Niveau** [Alch](./Alchimiste.md) 5, [Cham](./Chaman.md) 4, [Con](./Conjurateur.md) 4, [ConU](./conjurateur unchained.md) 5, [Hyp](./Hypnotiseur.md) 3, [Inq](./Inquisiteur.md) 4, [Ens](./Ensorceleur.md)/[Mag](./Magicien.md) 5, [Méd](./Médium.md) 3, [Occ](./Occultiste.md) 4, [Prê](./Prêtre.md) 4, [Psy](./Psychiste.md) 4, [Spi](./Spirite.md) 5

Grâce à ce sort le personnage peut, à n’importe quelle distance, entrer en contact avec une créature qu’il connait pour lui envoyer un message n’excédant pas vingt-cinq mots. Le sujet reconnaît automatiquement le personnage s’il l’a déjà rencontré et peut répondre immédiatement au message transmis. Les créatures ayant une [Intelligence](./Intelligence.md) extrêmement limitée ([Int](./Intelligence.md) 1) sont à même de comprendre le message, même si leurs capacités de réaction sont nécessairement réduites. Il n’est pas obligatoire pour le sujet de répondre au message envoyé.

Si le destinataire ne se trouve pas dans le même [plan](./Plans.md) que l’expéditeur, il y a 5 % de chances pour que le message n’arrive pas jusqu’à lui (dans certains cas, les conditions en vigueur dans certains [plans](./Plans.md) peuvent augmenter ce risque de façon considérable).

### Version mythique
{s:CMy}
Le personnage peut communiquer avec un nombre supplémentaire de créatures égal à son [grade](./Grade.md). Chaque créature reçoit le même message et peut répondre au personnage seulement.

**[Amplifié](./Amplifié.md) (3ème).** Si le personnage dépense deux utilisations de [pouvoir mythique](./pouvoir mythique.md), il peut transmettre le message à des créatures qu’il connaît mal (le nombre de créatures en question est le même que pour une communication à distance mythique non-amplifiée). Il doit décrire les destinataires prévus de manière générale ou précise (ça peut être « des orques », « la reine de cette contrée » ou « les demi-elfes masculins et gauchers ») ou définir des restrictions spécifiques telles que la portée, le type de créatures et l’alignement (ça peut être « l’ensemble des humanoïdes Bons à l’intérieur du château au sommet de la colline »). Si le nombre de créatures correspondant à la description est supérieur à la limite maximale imposée par le sort, ce sont les créatures les plus proches du personnage qui reçoivent le message.
