**École** [Divination](./école divination.md) ; **Niveau** [Apal](./Antipaladin.md) 1, [Cham](./Chaman.md) 0, [Dru](./Druide.md) 0, [Hyp](./Hypnotiseur.md) 0, [Inq](./Inquisiteur.md) 0, [Ens](./Ensorceleur.md)/[Mag](./Magicien.md) 0, [Occ](./Occultiste.md) 0, [Pal](./Paladin.md) 1, [Prê](./Prêtre.md) 0, [Psy](./Psychiste.md) 0, [Rôd](./Rôdeur.md) 1, [Sor](./Sorcière.md) 0  

**Temps d'incantation** 1 [action simple](./Action simple.md)  

**Composantes** [V, G](./composantes.md)  

**Portée** courte (7,50 m + 1,50 m/2 [niveaux](./niveau.md)) (5 {s:c} + 1 {s:c}/2 [niveaux](./niveau.md))  

**Cible ou zone d’effet** 1 créature, 1 objet ou 1 cube de 1,50 m (1 {s:c}) d’arête  

**Durée** [instantanée](./instantanée.md)  

**Jet de sauvegarde** aucun ; **Résistance à la magie** non

Ce sort indique si une créature, un objet ou un lieu a été empoisonné ou est toxique. Un test de [Sagesse](./Sagesse.md) de [DD](./DD.md) 20 permet de déterminer la nature exacte du poison. Si le lanceur de sorts maîtrise la compétence [Artisanat](./Artisanat.md) (alchimie), il peut tenter un test d’[Artisanat](./Artisanat.md) (alchimie) de [DD](./DD.md) 20 si le test de [Sagesse](./Sagesse.md) échoue ; il peut également choisir de réaliser ce test d’[Artisanat](./Artisanat.md) (alchimie) avant le test de [Sagesse](./Sagesse.md). Le sort fonctionne à travers les barrières si celles-ci ne sont pas trop épaisses : il est bloqué par 30 cm de pierre, 2,5 cm de métal, une mince feuille de plomb ou 90 cm de bois ou de terre.
