{s:UM}
**Niveau** 5

Les cibles d’un sort incluant ce méta mot doivent faire leurs [jets de sauvegarde](./jet de sauvegarde.md) deux fois et garder le plus mauvais résultat. Ce mot augmente de deux niveaux le niveau de tous les mots effet dans le sort qui autorisent un [jet de sauvegarde](./jet de sauvegarde.md).
