<div class="BD">
{s:BDTitre|Bésicles du mauvais œil|{s:AE}}
**Aura** [Nécromancie](./Nécromancie.md) modérée ; **NLS** 11 ; **Emplacement** [yeux](./Objets merveilleux portés sur les yeux.md) ; **Prix** 30.000 po ; **Poids** —
(((Description)))
Ces lunettes ressemblent à une paire de verres émeraude enchâssés dans une mâchoire pleine de crocs dorés. Le porteur peut utiliser le sort *[mauvais œil](./Mauvais œil.md)* 11 fois par jour et sur commande. Il affecte une cible par utilisation. Le porteur n’est pas obligé d’utiliser ces [rounds](./round.md) de manière consécutive mais chaque activation coûte une [action simple](./Action simple.md) (contrairement au sort qui nécessite une [action rapide](./Action rapide.md) pour changer de cible). Si le porteur retire les besicles, les effets de mauvais œil prennent fin immédiatement.
(((Création)))
**Conditions** [Création d’objets merveilleux](./Création dobjets merveilleux.md), *[mauvais œil](./Mauvais œil.md)*  ; **Coût** 15.000 po
